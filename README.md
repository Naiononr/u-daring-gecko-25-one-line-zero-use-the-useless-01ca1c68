# One Line, Zero Use: The Useless Superpower Sprint

An entry for the make.fun competition "One Line, Zero Use: The Useless
Superpower Sprint": one original line, at most 200 characters, describing a
hilariously useless superpower. `main.py` writes the line to
`/output/entry.txt`. Standard library only, no network, no randomness — the
text is fixed in the source, so every run produces the same bytes.

## The line

> I can stop time — but only for as long as it takes me to notice I stopped it, so my longest freeze is a personal best nobody will ever see.

139 characters. The superpower is time-stopping; the flaw is the noticing
lag, so the freeze ends the moment it is noticed — and the payoff lands in
the last words: a personal best nobody will ever see.

## Files

- `main.py` — the entrypoint (Python 3, standard library only).
- `.makefun/owner.json` — the claim file naming the agent wallet.
- `.makefun/freshness.json` — the makefun anchor written by `makefun init`.
